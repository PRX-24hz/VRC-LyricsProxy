# VRC-LyricsProxy

轻量、免注入的 Windows 桌面托盘工具，用于将网易云音乐实时歌词与 MagicChatbox 数据合并推送到 VRChat Chatbox。

---

## 项目背景与痛点

由于 VRChat 原生环境及现有 Chatbox 辅助工具无法直接获取原生网易云客户端的实时播放歌词，以往社区方案多依赖客户端注入（如 BetterNCM 插件，网易云一旦版本更新极易失效崩溃）；同时，多款 OSC 状态工具（如 MagicChatbox 的心率、时间、电量显示）在同时向 VRChat 发送数据时，会因抢占默认 9000 端口而导致互相冲突、文本覆盖。

本项目通过 Windows 系统级媒体总线（SMTC）免注入提取曲目信息与时间轴，并作为中间代理（Proxy）接管 OSC 数据流，实现 **MagicChatbox 状态（心率/时间/自定义文本）与实时歌词平滑双行合并推送**。

---

## 核心特性

* **系统级广播读取（SMTC）**：无需注入网易云进程或篡改文件，无惧网易云版本更新。
* **OSC 端口中继架构**：作为中间代理接收 MagicChatbox 发出的数据（默认 9005 端口），与解析出的歌词智能合并后统一投递给 VRChat（9000 端口），彻底解决端口抢占冲突。
* **通用状态透传与防断档**：全量接纳 MagicChatbox 的心率、系统时间、电量或自定义状态文本；内置宽容超时与空包过滤机制，避免状态行忽隐忽现。
* **144 字符防超长预算分配**：针对 VRChat `/chatbox/input` 的 144 字符物理上限，优先保留状态行，动态裁切歌词并追加省略号，杜绝消息被静默丢弃。
* **多歌词模式与智能翻译**：支持外文优先翻译（智能模式）、纯原文、纯翻译及双语对照模式。
* **单实例防多开**：内置 Windows 内核级互斥体检测，防止多次启动造成端口自身冲突。
* **极低开销**：单文件绿色打包，常驻系统托盘，静默占用低。

## 快速上手

### 1. 基础使用（仅显示歌词）
1. 解压下载的压缩包，双击运行 `VRC-LyricsProxy.exe`。
2. 运行后程序会常驻在任务栏右下角托盘区。
3. 打开网易云音乐播放歌曲，进入 VRChat 即可在 Chatbox 看到歌词滚动。

### 2. 进阶使用（MagicChatbox + 歌词合并）
1. 打开 **MagicChatbox** 客户端。
2. 将其 **OSC 发送端口（Send Port）** 从默认的 `9000` 修改为 `9005`（发送 IP 保持 `127.0.0.1`）。
3. 确保 `VRC-LyricsProxy.exe` 正在运行。
4. 进入 VRChat，即可在头顶 Chatbox 看到：
   * **第一行**：MagicChatbox 投递的内容（心率 / 时间 / 电量 / 自定义文案）
   * **第二行**：网易云当前播放的歌词

## 配置与设置

* **打开设置面板**：右键任务栏右下角托盘图标，点击 **设置...**。
* **参数说明**：
  * **监听端口**：默认 `9005`，对应 MagicChatbox 的发送端口。
  * **VRChat 目标端口**：默认 `9000`，对应 VRChat 默认 OSC 接收端口。
  * **歌词显示模式**：可选智能模式、纯原文、纯翻译、双语对照。

## 常见问题与已知限制 (FAQ)

### Q: 手动拖动歌曲进度条后，歌词不同步了怎么办？
* **说明**：为保证免注入的轻量与绝对稳定性，本工具基于系统切歌事件与时间戳推算播放轴，无法主动感知网易云客户端内的手动进度拖拽。
* **解决办法**：切到下一首歌，或者在播放列表重选歌曲即可重新对齐时间轴。

### Q: 为什么第一行只显示歌词，不显示 MagicChatbox 的内容？
1. 检查 MagicChatbox 的 OSC 发送端口是否已修改为 `9005`。
2. 若开启了心率，请确认心率数据源正在持续更新（无数据超过 15 秒会自动回退为单显歌词）。
3. 检查是否有残留的旧进程占用了 9005 端口。

### Q: Windows 提示“未知发布者 / 已保护你的电脑”？
* 本工具为个人免费开源软件，未购买商业代码签名证书。
* 提示属于 Windows SmartScreen 的正常机制，点击 **“更多信息” -> “仍要运行”** 即可。
